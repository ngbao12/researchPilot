    MODEL CONNECTION

    Kết nối cách bạn đọc.

    Dùng bằng chứng offline, hoặc kết nối model để tổng hợp câu trả lời.

    Nhà cung cấp

    Model tương thích Chat Completions. Nhập đúng ID được cấp quyền trên tài khoản của bạn.

    Kiểm tra quyền truy cập model, không tạo câu trả lời.

    Key nhập ở đây chỉ giữ trong tab. Key Groq mặc định nằm trong cấu hình local trên máy, không gửi về trình duyệt. Câu hỏi và đoạn trích được gửi tới nhà cung cấp đã chọn; phí API tính trên tài khoản tương ứng.
